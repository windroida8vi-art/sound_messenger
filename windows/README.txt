HiddenAudio -- Windows (نسخه ویندوزی همون اپ اندروید)
======================================================

این همون اپه (آهنگ مخفی) ولی برای ویندوز، با همون پروتکل صوتی، همون
رمزنگاری AES-256، همون قابلیت فرستادن متن/عکس، و همون لود زنده‌ی عکس.
چون پروتکل صدا دقیقاً همونیه که تو اندروید هست، این اپ ویندوزی و گوشی
اندرویدی می‌تونن با هم حرف بزنن (مثلاً از گوشی بفرستی، از ویندوز بگیری یا برعکس).

نصب و اجرا
----------
1. پایتون 3.10 یا بالاتر لازمه (از python.org نصب کن، تیک "Add to PATH" رو بزن).
2. تو پوشه‌ی پروژه (همین پوشه) این دستور رو بزن:

       pip install -r requirements.txt

3. اجرا کن:

       python main.py

ساخت یک فایل exe مستقل (اختیاری)
--------------------------------
اگه می‌خوای بدون نصب پایتون روی یه کامپیوتر دیگه هم اجرا بشه:

       pip install pyinstaller
       pyinstaller --onefile --windowed --add-data "assets;assets" main.py

فایل خروجی تو پوشه‌ی dist ساخته می‌شه.

نکات مهم
--------
- میکروفون و بلندگوی کامپیوتر باید کار کنن (اگه چند تا دستگاه صدا داری و
  درست کار نکرد، از تنظیمات ویندوز دستگاه پیش‌فرض ضبط/پخش رو چک کن).
- فرمت آهنگ: mp3 / wav / ogg / flac پشتیبانی می‌شه (اگه آهنگی پخش نشد،
  یه فایل wav امتحان کن، چون پخش mp3 به کتابخونه‌ی صوتی سیستم بستگی داره).
- رمز عبور رو هیچ‌وقت داخل همون آهنگ نفرست؛ جدا (حضوری، پیامک، و…) بگو.
- این یه پروتوکل آزمایشی/خانگیه، نه یه استاندارد امنیتی رسمی؛ خود رمزنگاری
  (AES-256-GCM) استاندارد و قویه، فقط رمز عبورت رو قوی انتخاب کن.

فایل‌های پروژه
--------------
main.py            - رابط کاربری (Tkinter) و موتور فرستنده/گیرنده
audio_codec.py      - پروتکل صوتی (sync tone + FSK + CRC) - پورت AudioCodec.kt
crypto_util.py      - رمزنگاری AES-256-GCM - پورت Crypto.kt
stream_decoder.py   - رمزگشای زنده/پیش‌رونده - پورت StreamDecoder.kt
assets/background.jpg - (اختیاری) عکس پس‌زمینه؛ اگه نباشه گرادیانت تیره استفاده می‌شه
